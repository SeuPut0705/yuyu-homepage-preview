새 기안

양식을 고르면 입력 화면과 결재선 미리보기가 열립니다.

내 결재함
  • 증명서 발급 신청 임시재직·경력증명서 신청(F-01, 임시 양식). 인사 담당이 확인하고 승인하면 인사 DB 값으로 PDF가 발급됩니다.결재선 인사 담당 확인
  • 법인카드 사용 임시법인카드 사용 내역 결재(E-02, 임시 양식). 카드 승인번호가 같은 내역은 두 번 올릴 수 없습니다.결재선 팀장 → 회계 합의 → 본부장
  • 지출결의서 임시지출 결의(임시 양식). 회계 합의·법인카드 구분은 인터뷰 뒤에 정합니다.결재선 팀장 → 회계 합의 → 본부장
  • 연차 신청 임시연차·반차 신청(E-09, 임시 양식). 일수는 주말·공휴일을 빼고 계산합니다.결재선 팀장 → 본부장 → 참조 인사
  • 원료 출고 승인 임시연구소 원료 출고 승인(E-08, 임시 양식). 승인되면 ERP 기타출고 대상으로 기록만 남깁니다. ERP에는 쓰지 않습니다.결재선 팀장 → 품질 합의(연구소 밖 요청) → 연구소장 → 본부장
  • 품의서 임시일반 품의(임시 양식). 항목과 결재선은 양식 인터뷰 뒤에 바뀝니다.결재선 팀장 → 본부장
  • 구매 품의 임시구매 품의(E-01, 임시 양식). 승인되면 ERP 발주 가능 전환 대상으로 기록만 남깁니다. ERP에는 쓰지 않습니다.결재선 팀장 → 구매 합의 → 회계 합의(예산 외) → 본부장 → 대표
  • 견적서 결재 임시견적서 결재(E-03, 임시 양식). 신제품이거나 납품가가 바뀌는 견적을 영업이 올립니다.결재선 팀장 → 품질 합의(신제품) → 본부장
  • 근무 보정 요청 임시출근·퇴근 기록을 바로잡는 요청(F-05, 임시 양식). 승인되면 보정 줄이 더해지고 원래 기록은 그대로 남습니다.결재선 팀장(본인이 팀장이면 상위 조직장) → 참조 인사
